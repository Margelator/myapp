把 Docker 学成每天都用得上的技能

沿着镜像、容器、网络、数据卷、Compose 和部署这条主线练习，不堆概念，先跑起来，再理解为什么。

开始学习 查看速查 
$ docker run hello-world
$ docker build -t my-api .
$ docker compose up -d
$ docker logs -f my-api

四步建立学习节奏

每一步都有明确产出：能运行、能解释、能排错、能迁移到自己的项目。

01

理解镜像和容器

掌握 image、container、tag、registry 的关系，知道一次运行背后发生了什么。

02

写出 Dockerfile

从基础镜像、复制文件、安装依赖到启动命令，构建自己的第一个应用镜像。

03

连接服务与数据

练会端口映射、容器网络、环境变量和数据卷，让应用能稳定运行。

04

用 Compose 编排

把 Web、数据库、缓存写进同一个 compose 文件，形成可复现的本地环境。

首页推荐先学这些

模块按实际项目出现频率排序，适合每天投入 30 到 60 分钟逐个击破。

镜像构建

理解分层缓存、构建上下文、`.dockerignore`，让镜像更小、更快、更稳定。

网络通信

搞清楚宿主机端口、容器端口、自定义网络和服务名解析，少走排错弯路。

数据持久化

用 volume 和 bind mount 保存数据库、配置文件和开发目录，避免容器删除后数据消失。

第一天就能跑通

  • 安装 Docker Desktop，并确认 Docker Engine 正常运行
  • 运行 hello-world，熟悉拉取镜像和创建容器
  • 用 nginx 映射本地端口，打开浏览器验证结果
  • 写一个最小 Dockerfile，构建并启动自己的镜像
# 查看版本与运行状态
docker version
docker ps

# 拉取并运行一个服务
docker pull nginx
docker run --name web -p 8080:80 -d nginx

# 构建、查看、清理
docker build -t docker-study .
docker images
docker stop web
docker rm web
